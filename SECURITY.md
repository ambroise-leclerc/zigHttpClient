# Security Policy

## Supported Versions

Only the latest release of this project is supported.

## Security Scope

This project implements a plain HTTP client. It does not support TLS/HTTPS and provides no encryption or transport security guarantees. It is intended for use in trusted environments or behind a secure proxy. Do not use this client for transmitting sensitive data over untrusted networks.

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it responsibly.

To report a vulnerability, please open a security advisory through the repository's official channels. We will acknowledge your report and work with you to address the issue promptly.
